# Hospedagem-de-um-Hotel-no-C-
Mini projeto desenvolvido em C# com o objetivo de praticar conceitos de Programação Orientada a Objetos (POO). O sistema permite cadastrar hóspedes, definir suítes e realizar reservas, calculando a quantidade de hóspedes e o valor total da hospedagem, incluindo desconto de 10% para reservas com mais de 10 dias.
